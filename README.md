# FN Traduction — Site web

Site vitrine bilingue (Français / বাংলা) pour **FN Traduction** :
traduction assermentée, traduction normale, interprétation téléphonique et
présentielle, services administratifs, et lien vers FN Formation.

## Pages

- `index.html` — Accueil
- `traduction.html` — Traduction assermentée & normale
- `interpretation.html` — Interprétation téléphonique & présentielle
- `services.html` — Autres services / aide administrative
- `formation.html` — FN Formation (lien vers fnformation.com)
- `devis.html` — Formulaire de devis gratuit

## Publier sur GitHub Pages

1. Créez un dépôt GitHub et envoyez-y le contenu de ce dossier.
2. Allez dans **Settings → Pages**.
3. Source : branche `main`, dossier `/ (root)` → **Save**.
4. Le site sera disponible à l'adresse `https://<utilisateur>.github.io/<depot>/`.

## Personnalisation

- **E-mail / téléphone** : remplacez `contact@fntraduction.fr` et `+33 7 58 12 34 56`
  dans tous les fichiers `.html` et dans `js/main.js` (adresse du formulaire).
- **Formulaire de devis** : il utilise `mailto:` (ouvre le logiciel e-mail du
  visiteur). Pour recevoir les demandes automatiquement, connectez-le à un
  service comme Formspree ou Web3Forms.
